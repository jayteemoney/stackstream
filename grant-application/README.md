## What sets this application apart

1. **It is already on mainnet.** Not an idea, not a testnet demo. Contracts deployed, streams running, receipts public.

2. **A public register, not a claim.** Every organisation that registers appears in a list read live from the contract, with a receipt anyone can check in ten seconds.

3. **First-mover on Stacks.** Every major smart contract platform has payment streaming except Stacks. StackStream is the first on Stacks.

4. **sBTC-ready from day one.** The SIP-010 abstraction means any token on Stacks works, including sBTC. Native STX cannot be streamed, and the documents say so.

5. **Low execution risk, and honest reporting.** Grant funds hardening and adoption, not research. The hard engineering is done. The numbers are small and published anyway, including the ones that are behind.
